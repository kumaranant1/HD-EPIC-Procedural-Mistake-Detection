## Mistake Stream JSON Structure

The final mistake stream file is:

```text
data/processed/hd_epic_mistake_streams.jsonl
```

Each line is one JSON object for one procedural stream after one mistake has
been injected. The important fields are:

- `stream_id`: id for the new mistake stream.
- `source_stream_id`: id of the original clean procedural stream.
- `actions`: the chopped action stream. It contains every action before the
  mistake, plus the one replacement mistake action at the end.
- `mistake_mask`: one label per action in `actions`. Previous normal actions
  are `0`; the final mistake action is `1`.
- `mistake`: metadata from the LLM explaining the injected mistake.

So conceptually the stream is:

```text
actions      = [normal_0, normal_1, normal_2, ..., mistake_action]
mistake_mask = [0,        0,        0,        ..., 1]
```

The stream is always chopped immediately after the mistake. There are no actions
after the mistake action in the final mistake stream.

The `mistake` object stores the LLM output in structured form:

```json
{
  "target_index": 33,
  "original_action_text": "original clean action text",
  "mistake_action_text": "replacement mistake action text",
  "mistake_type": "wrong_ingredient",
  "why_this_action_is_critical": "...",
  "why_goal_breaking": "...",
  "why_observable_now": "...",
  "why_hard_to_recover": "...",
  "why_plausible": "...",
  "detectability": "subtle",
  "confidence": "high"
}
```

The `target_index` is the position of the original action that was replaced.
Because the stream is chopped at the mistake, the last action in `actions` should
have the same index as `mistake.target_index`, and the last value in
`mistake_mask` should be `1`.

The action objects may still contain fields from the original HD-EPIC procedural
stream, such as `action_id`, `video_id`, `start`, `end`, `verbs`, `nouns`, and
`main_actions`. These are copied from the source stream for traceability. They
are not newly inferred by the mistake parser. The mistake parser only changes
the final action's `text` to the LLM-generated `mistake_action_text` and adds
small mistake-related fields such as `is_mistake`, `mistake_type`, and
`original_text`.

For model training, the minimal fields to use are usually:

- `stream_id`
- `actions`
- `mistake_mask`
- `mistake`
